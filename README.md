# Smart Network Monitoring and Management System

A web-based Network Monitoring and Management System developed for monitoring network devices, bandwidth usage, alerts, and reports through an admin dashboard.

## Project Overview

The system provides a centralized dashboard to monitor network devices and analyze network performance. It helps administrators track device status, bandwidth consumption, alerts, and generate reports.

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- AdminLTE
- Chart.js
- Cisco Packet Tracer

## Features

### Admin Dashboard
- Secure Admin Login
- Device Statistics
- Online/Offline Device Monitoring
- Network Traffic Charts
- Live Date and Time

### Device Management
- Add Devices
- Edit Devices
- Delete Devices
- Search and Filter Devices

### Bandwidth Monitoring
- Upload/Download Speed Monitoring
- Bandwidth Usage Analysis
- Usage Percentage Calculation
- Graphical Reports

### Alert Management
- Offline Device Alerts
- High Bandwidth Alerts
- Alert History

### Reports
- Network Reports
- Print Reports
- Export Reports

## Network Topology

The project includes a Cisco Packet Tracer network topology containing:

- Router
- Switch
- Server
- Wireless Access Point
- Client Devices
